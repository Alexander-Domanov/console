# console

The interactive part of my GitHub profile: a terminal you can type into, a studio
where you can record a beat that then plays on the main page, and a tape deck
that boots DOOM shareware from 1993.

Everything is static. No build step, no framework, no third-party widget service.
Audio is synthesised in the browser with Web Audio, there are no samples.

- `/` the console
- `/studio.html` the studio, four pads and a record button
- `/doom.html` tape side B
